# 第五章示例输入格式

本目录由 MATLAB `ExportReferenceData.m` 从原始 `CaseNo_12.mat` 及受保护的 HA* 初始化结果导出。C++ 和 Python 使用内容一致的两份输入。这里没有 LIOM 优化后的轨迹；`reference.csv` 仅为算法 5-1 的初始参考。

所有 CSV 均无表头、十进制浮点数、逗号分隔，单位为 m、s、rad。

| 文件 | 格式 |
| --- | --- |
| `reference.csv` | 200 行、11 列：`x,y,theta,v,a,phy,w,xf,yf,xr,yr` |
| `dilated_map.csv` | 125×125 的二值膨胀占据地图；行对应 x 索引、列对应 y 索引；0 可用、1 占据 |
| `obstacles.csv` | 每行 `obstacle_id,x,y`；同一障碍物的顶点连续排列，源场景为凸多边形 |
| `parameters.csv` | 1 行、28 列，顺序如下 |

`parameters.csv` 列号从 1 开始：

| 列 | 参数 |
| --- | --- |
| 1 | 配置点数 N=200 |
| 2–5 | 场景 xmin,xmax,ymin,ymax |
| 6–9 | 轴距、前悬、后悬、车宽 |
| 10–13 | 速度、加速度、前轮转角、转角速率绝对值上限 |
| 14–15 | 走廊扩张步长、单方向最大扩张长度 |
| 16–17 | 不可行度阈值、完整解变化量阈值 |
| 18–19 | 初始罚权、罚权递增系数 |
| 20–21 | 加速度与转角速率二次项权重 |
| 22–24 | 起点 x,y,theta |
| 25–27 | 终点 x,y,theta（与参考轨迹相同的连续角度分支） |
| 28 | 初始总时间 T |

速度及前轮转角在首末节点为零；加速度及转角速率在末节点为零。起终点双圆圆心由边界位姿计算并固定。时间范围沿用原始实验实现 `[0.1, N*0.5]` 秒。

输入成套使用。若修改场景，需生成相应的参考轨迹、膨胀地图、障碍物及边界参数，不能仅移动障碍物而继续使用旧地图。MATLAB 版可重新运行保护模块并导出完整输入。
